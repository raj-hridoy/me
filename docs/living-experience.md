# Living experience — interaction upgrade

The static dark architectural design is approved and preserved. The preceding final production captures are archived in `.qa/living/before/`. Colors, fonts, RH identity, editorial layouts, content, and destinations remain the foundation.

## Inspection and direction

The existing system has coordinated entries, bounded desktop parallax, pointer lighting, native controls, layer selection, and a credible caller/policy model. The audit identified an absent signature cursor, immediate architecture geometry changes, disconnected hover feedback, abrupt filter/methodology switches, and room for event-driven ambient progression. No graphics or animation dependencies are needed.

The upgrade adds one square optical scope language, coherent target framing, brief scans and activation feedback, interruptible SVG architecture transitions, direct diagram inspection, and context-driven ambience. Every enhancement preserves native keyboard, text selection, touch, and reduced-motion behavior. Decorative overlays do not intercept input. Effects stop when idle, hidden, or offscreen.

## Implemented system

- `ScopeCursor` owns one fine-pointer listener and one queued animation frame. Four corner brackets, a square center, contextual labels, target framing, a 720ms scan, and a short activation contraction share the existing blue/platinum tokens. Pointer movement does not set React state. Scroll drift is capped at 5px and cleared after 160ms.
- Reading, fields, code, selections, keyboard interaction, forced colors, reduced motion, and touch preserve native pointer behavior. The native pointer is hidden only after a successful paint and only while the visible overlay exists. The fixed, clipped, noninteractive overlay cannot intercept clicks or enlarge the page. A simulated unavailable animation API verifies fallback while the native control continues working.
- Pointer presence directs existing light, shifts the hero grid by at most 4px, and tilts research artwork by at most two degrees. A surface returns to rest when the pointer moves away. The extra grid is disabled at phone/tablet widths.
- Architecture nodes select identity, policy, and resource planes. A native focus button animates the selected view and restores the overview. SVG geometry interpolates for 480ms, resumes from the actual intermediate geometry when interrupted, and settles immediately for direct dragging, reduced motion, hidden documents, or offscreen diagrams.
- Five native request nodes expose the corresponding stages in both desktop and dedicated phone diagrams. The existing caller/ownership/grant model remains authoritative; educational examples and results remain unchanged. A reduced-motion change during a trace resolves its genuine outcome immediately.
- Visible sections advance structural lines through batched geometry reads and writes. Existing bounded native-scroll architecture parallax and entrance choreography remain. Filters, methodology phases, link arrows, mobile menu stagger, and angular copy confirmation receive concise feedback. Route navigation stays native with a 220ms acknowledgment.

The implementation uses existing React, native SVG, CSS, Web Animations, and browser observers. No dependency or lockfile changes, font/palette replacements, new graphics engines, continuous canvas redraws, or invented portfolio evidence were introduced.

## Rendered refinement

Before evidence is in `.qa/living/before/`. The first desktop pass captured all five scope modes, architecture transitions, focusing, and intermediate/completed request states. Actual review found the focused architecture crossing the BREAKS headline. Its view was reduced and shifted to keep the headline clear; clipped technical annotations are hidden while focused. Target classification was refined so the focus control behaves as a button while native nodes use inspection mode. Pointer lighting and depth now clear on the previously hovered surface.

The second pass captured the desktop and touch-emulated phone at 1440 and 390px: resting home, intermediate layer geometry, focused layer, moving/completed trace, reduced motion, filtered archive, and mobile navigation. These rendered states were visually inspected. The first capture process closed during an archive route change on this host's single-process Chromium; the helper now uses a fresh browser for the archive. The complete second pass recorded no page errors, no desktop pointer-edge overflow, and **zero animation-frame callbacks during a settled one-second interval on both widths**. This is measured idle behavior, not a claim of zero rendering cost during interactions.

Initial cursor test failures used a pointer-events-disabled title as a hover target. They were corrected to use the actual underlying composition target, without forced pointer events or changed application assertions. The tested modes and native fallback then passed. An existing rotation test also began its drag on the new center inspection button. Its start point was moved onto the drawing surface, retaining the original 90-degree rotation assertion and adding a wait for the deliberate geometry transition; native inspection-node behavior is tested separately. The first full production run passed the other 26 tests, including both route-wide accessibility scans.

## Verification

The final production build passed; the complete suite passed **27 tests in 3.3 minutes**. Axe found zero violations on all nine routes at phone and desktop widths. The separate audit passed **54 route/width combinations**.
